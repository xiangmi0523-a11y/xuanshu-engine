# 六爻装卦与八字查表（E2-A 第 1 项）

## 依据
- 规则：契约附录 R-39 P-B-01～06（装卦）、P-A-02/03/06（八字查表）；准入：【用户裁决 M1-R、M2-R】。
- 静态表：`data/static/*.csv`（10 张），由数据仓库 `static/gen_static_tables.py` 从 Muse M-1、M-2 回填表生成，哈希登记于 `data/static/MANIFEST.json`，`check:data` 逐个校验。引擎核心不读文件，表以文本传入 `parseStaticTables`。
- 验证分三层（L1 字节锁定、L2 运行时语义、L3 独立正确性），约束清单见 `docs/static_semantics.md`，独立基准见 `vectors/static_oracle.json`。以下为 L1、L2 的说明。
- 两道独立防线：`check:data` 核对**文件哈希**（防表被改动）；`parseStaticTables` 做**运行时语义校验**（防不合契约的表进入计算，无论哈希来自哪里）。语义校验内容：表头与行列数；每张表的键合法、不重复、齐全；取值合法；六十四卦上下卦与卦画一致、世爻与宫内位置合 P-B-03、应＝世＋3、本宫为纯卦、每宫 8 卦且宫内位置各一；六神为固定次序的轮转（P-B-05）；旬空的旬首与空亡与日干支对应（P-B-06）；藏干本气必有、行内不重复、无中气则无余气；十二长生十二支不重复、阳干顺行阴干逆行、戊同丙己同丁（R-39.10 第 4 项）。任一不合即 `STATIC_TABLE_INVALID`，不返回部分结果。

## 装卦 `computeZhuanggua(yao, dayGanzhi, tables)`
顺序固定：起卦 → 寻宫 → 纳甲 → 安世应 → 安六亲 → 安六神 → 排日辰 → 判动变。

| 步骤 | 做法 | 依据 |
|---|---|---|
| 寻宫、世应 | 查六十四卦表（八宫、宫内位置、世、应） | P-B-01、P-B-03 |
| 纳甲 | 初～三爻取下卦的内卦纳甲，四～上爻取上卦的外卦纳甲 | P-B-02 |
| 六亲 | 以**本卦宫五行**为我；变卦六亲仍依本卦宫 | P-B-04 |
| 六神 | 按日干起，初爻至上爻；只排本卦；`liushen_is_auxiliary_symbol: true`，不参与生克 | P-B-05 |
| 旬空 | 按占日日辰查六旬空亡表 | P-B-06 |

- 结果带层级标注 `layer`：京房纳甲体系（后世术数，非《周易》原文）。
- 变卦不排六神、不标世应（【用户裁决 M3-R】第 1、2 项，契约 R-39.11）：变卦对象只含卦名、宫、宫内位置与各爻纳甲、五行、六亲（依本卦宫），类型上即无 `shi`、`ying`、`liushen` 字段。依据均为“由例推定”（四书无明文）；世应一项经 M-3b 古吴版扫描本复核 W03、W04 一致，证据等级升为已证实（契约 R-39.12）。结果的 `conventions` 列出这两条及依据，`pending` 目前为空。
- 未实现（`not_implemented`）：月建与月破（P-B-07）、飞伏（P-B-09）、断语与旺衰。这些未在本轮静态表查证范围内，需另行准入。
- 阻断：日辰不是六十甲子之一 → `DAY_GANZHI_INVALID`；静态表表头、行数、取值不合 → `STATIC_TABLE_INVALID`。

## 八字查表
- `shishenOf(日干, 他干)`：十神（以日干为我）。别名（七杀＝偏官）在展示层处理，引擎输出表中名称。
- `cangganOf(地支)`：本气、中气、余气，带层级“现代整理层”；《渊海子平》歌诀只给所藏之干，次序不由原文定。
- `changshengOf(天干, 地支)`：十二长生状态，带层级“术数传承层；阴干阳顺阴逆、戊己火土同宫；旺衰不等于吉凶”。
- `baziDetail(四柱)`：汇总各柱天干十神（日柱为“日主”）、藏干及其十神、日主在各支的十二长生。输入须为 3 柱（时柱未知时不传）或 4 柱，每柱为六十甲子之一，否则 `PILLARS_INVALID`。
- 只查表：不判格局、旺衰强弱、吉凶；人元司令仍暂缓（P-A-04）。
