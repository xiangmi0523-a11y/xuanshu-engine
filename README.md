# xuanshu-engine · 玄枢计算引擎（纯计算核心）

依据【用户裁决 B3-1】（有边界工程启动）建立。契约正本与冻结数据在私有仓库 `xuanshu-data`。

## 边界（不可越过）

- **只做纯计算**：不引入界面框架、数据库驱动或平台专属 API（D2）。TypeScript 只是当前阶段的实施语言，**不代表技术栈已冻结**（D3）。
- **不联网、不接 AI**（裁决 5、W-13）。
- **不产生持久化业务数据**：数据库只允许在测试进程内存中临时建立（D1，E2 阶段起），不得落盘，不得成为 App 可用的数据资产。
- **不自判对错**：引擎只产出测试输出；与冻结基准的比对由 `xuanshu-data/harness/` 独立执行（D4、B4-11）。
- **不解除任何阻断**：B1～B4 与 BLK 的解除须单独验收、由用户确认。

## 目录

| 路径 | 内容 |
| --- | --- |
| `src/` | 纯计算核心 |
| `test/` | 单元测试（Node 内置测试框架） |
| `data/frozen/` | 冻结数据只读副本 + `MANIFEST.json`（哈希以契约登记为准） |
| `scripts/` | CI 检查：W-01 禁令、隔离（依赖白名单 / 无网络 / 无生成脚本 / 无数据库文件）、冻结数据哈希 |
| `reports/` | 每阶段的验收证据 |

## 阶段（B3-1 第五节）

E0 环境与基线 → E1 纯计算核心 → E2 数据库结构准备（内存临时库）→ E3 独立回归与验收。

## 本地运行

```
npm ci --ignore-scripts
npm run ci
```

工具链锁定：Node 22.23.5（`.nvmrc`）、TypeScript 5.9.3、@types/node 22.20.5（`package-lock.json`）。
