# E1 补齐 · 追加：六爻八卦识别缺陷修正

- 日期：2026-11-20
- 发现经过：为 UI 设计稿制作六爻示例（乾为天初九动）时，引擎给出的变卦下卦为“兑”，按通说应为“巽”（天风姤）。
- 用户指示：修正（“继续你发现的优化”）。范围仅限 `src/liuyao.ts` 的八卦识别与对应测试，不涉及八字、数据、契约。

## 缺陷与根因

- `TRIGRAMS` 表的键实际是按 初→上 写的（震 100、艮 001、兑 110、巽 011），代码注释却误称“按 上→下 书写”，并在查表前把输入反转了一次。
- 后果：对称的乾、坤、离、坎不受影响；**震↔艮、巽↔兑互换**。任何含这四卦的本卦、变卦名称都错。
- 原测试未发现：只测了乾和离（对称卦），另一条断言“上卦 = 兑”本身是按错误逻辑写的（输入 阴阳阳 应为巽）。

## 修正

- `src/liuyao.ts`：去掉反转，按 初爻在前 直接查表；注释写明键序与四个非对称卦的口诀。
- `test/liuyao.test.ts`：
  - 改正原断言：下离上巽（风火家人），原写“兑”。
  - 新增：八卦 8×8 = 64 种上下卦组合，全部按口诀（乾三连、坤六断、震仰盂、艮覆碗、离中虚、坎中满、兑上缺、巽下断）在测试内独立写出，不引用引擎的表。
  - 新增：乾为天初九动 → 天风姤；坤为地初六动 → 地雷复。
